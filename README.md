# 🏋️‍♀️ Janafit: Продажи курсов в Telegram & Mini App

Быстрая монетизация и выдача доступа к курсам тренировок Janafit.

## 🎯 Оффер и экономика
* **Спеццена:** `4 990 ₸` вместо `8 900 ₸` (-44%)
* **Логика воронки:** No Friction (ноль барьеров). Пользователь переходит по ссылке, видит оффер, оплачивает через Kaspi / Карту и мгновенно получает доступ к тренировкам.

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Заполните в `.env`:
* `BOT_TOKEN` — токен бота от @BotFather.
* `ADMIN_IDS` — ваш Telegram ID (чтобы подтверждать чеки Kaspi и смотреть статистику).
* `PRIVATE_CHANNEL_ID` — ID закрытого канала с тренировками (бот автоматически создает одноразовую ссылку `member_limit=1` каждому покупателю).
* `KASPI_PHONE` — номер телефона для Kaspi перевода / Kaspi Pay.
* `ROBOKASSA_LOGIN`, `ROBOKASSA_PASSWORD_1`, `ROBOKASSA_PASSWORD_2` — ключи эквайринга Robokassa.
* `GEMINI_API_KEY` — ключ Google Gemini для работы круглосуточного AI-тренера.

### 3. Запуск системы
```bash
python3 main.py
```
После запуска:
* Telegram бот начинает слушать команды.
* Веб-сервер FastAPI запускается на порту `8000` (обрабатывает Webhook Robokassa и отображает Telegram Mini App по адресу `/app`).

## 🎬 1. Инструкция по нарезке и переупаковке тренировок

1. **Формат нарезки:**
   * Урок длится **20–30 минут** (разминка 3 мин, основная часть 18–22 мин, заминка 3 мин).
   * Добавьте фирменную плашку Janafit в углу (таймер работы/отдыха, например 40 сек работа / 20 сек отдых).
   * Подпишите упражнения и подсказки по дыханию (*«Выдох на усилии»*, *«Не прогибайте поясницу»*).

2. **Загрузка видео:**
   * **Вариант 1 (Рекомендуемый для Telegram):** Загрузите видео напрямую в закрытый Telegram-канал. Telegram бесплатно хранит файлы до 2 ГБ, они мгновенно стримятся и не имеют рекламы.
   * **Вариант 2 (Для Mini App / Сайта):** Залейте видео на Kinescope / YouTube (доступ по ссылке) или Vimeo и вставьте ссылки в `mini_app/index.html`.

## 💳 2. Схема приема платежей

1. **Kaspi (90% оплат в Казахстане):**
   * **Авто-оплата Kaspi Pay:** клиент оплачивает по удаленному счету или Kaspi QR.
   * **MVP-режим с чеками:** клиент переводит 4 990 ₸ на Kaspi и скидывает квитанцию в бот. Куратор/администратор в один клик жмет кнопку `[ ✅ Одобрить доступ ]` прямо в Telegram, и бот мгновенно отправляет клиенту доступ и персональную ссылку в закрытый канал.

2. **Robokassa:**
   * Автоматический прием оплат с карт Visa, Mastercard, Мир и международных карт.
   * Бот получает webhook на `/robokassa/result` и выдает доступ мгновенно без участия человека.

## 🤖 3. Поддержка: AI-тренер и живые кураторы

* **AI-тренер (24/7):** встроен в бот на базе Gemini. Мгновенно подсказывает замену упражнений при боли в коленях/спине, рассчитывает баланс воды и КБЖУ, мотивирует не бросать курс.
* **Живой тренер:** по кнопке *«💬 Написать живому куратору»* вопрос пересылается в чат кураторов, где тренер может ответить текстом или записать голосовое/видео с разбором техники.

## 📱 4. Мобильное приложение (Telegram Mini App)

В папке `mini_app/` уже реализовано веб-приложение:
* Адаптировано под смартфоны и Telegram WebApp SDK.
* Интерактивный трекер 21 дня (отметка выполненных тренировок).
* Встроенный интервальный таймер подходов (40/20 сек) с виброоткликом (Haptic Feedback).
* В будущем этот же интерфейс собирается в нативное приложение для App Store и Google Play через **Capacitor** или **Flutter**.
